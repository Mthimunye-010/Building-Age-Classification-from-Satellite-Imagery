# Building Age Classification Using Machine Learning

## Project Overview

This project focuses on classifying buildings into four age categories using Landsat spectral features and machine learning.

The study uses data from two cities, Madrid and Amsterdam, to investigate how well machine learning models can classify building ages and generalise across different geographical locations.

## Objectives

- Classify buildings into four age categories.
- Explore Landsat spectral features.
- Develop and evaluate machine learning models.
- Compare Random Forest and XGBoost.
- Investigate cross-city model generalisation.

## Machine Learning Models

- Random Forest
- XGBoost

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn

## Project Structure

- `notebooks/` contains the analysis, preprocessing and modelling notebooks.
- `data/` contains information about the datasets and instructions for obtaining them.
- `results/` contains model evaluation outputs.
